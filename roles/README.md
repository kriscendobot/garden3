# Roles

A role is `roles/<role>/AGENT.md`: what an agent doing that work is for, which
skills it uses, its norms, and when it is done. The names are chosen so that a
harness does not load them by itself; an agent reads the ones its job names.

| Role | Lives on | Does |
| --- | --- | --- |
| [COMMON](COMMON.md) | the shed | what every role shares |
| [steward](steward/AGENT.md) | the shed | hears the maintainers, posts and settles jobs, publishes |
| [accountant](accountant/AGENT.md) | the shed | the weekly slate; reviews engagements that keep re-planning |
| [planner](planner/AGENT.md) | the shed | stands in for a job that ran out of time: plans the rest and dispatches it |
| [librarian](librarian/AGENT.md) | the shed | answers one question from the library and the garden, with citations |
| [PLOT](PLOT.md) | each plot | what the working roles on a plot share |
| [builder](builder/AGENT.md) | each plot | makes the change |
| [designer](designer/AGENT.md) | each plot | writes the design a change needs first |
| [reviewer](reviewer/AGENT.md) | each plot | reads a change before a maintainer has to |

This is the whole set. More are adopted when a job needs one
([designs/upstream.md](../designs/upstream.md)); the prior garden has
thirty-nine to draw on.
